## 1. 项目目标与研究问题

### 1.1 预测什么

对股票 i，在时刻 t 使用当时已知的订单簿、集合竞价信息、历史记录，以及推理时已经收到的同一时刻其他股票信息，预测未来 60 秒相对合成市场指数的价格变化。

概念上，标签为：

```text
target = 10,000 × [WAP_stock(t+60) / WAP_stock(t)
                  − WAP_index(t+60) / WAP_index(t)]
```

训练使用数据提供的 `target`，不擅自重建标签。这是连续值回归：正值表示相对跑赢市场，负值表示相对跑输市场，不等于股票自身一定上涨或下跌。

### 1.2 怎样评价

- 主指标：MAE，越低越好。
- 辅助诊断：逐日 MAE、各时间验证折 MAE、股票/收盘阶段分组误差、横截面 IC / RankIC。
- 工程指标：训练耗时、推理耗时、峰值内存、特征数量。
- MAE 改善不直接代表可交易收益；本项目第一阶段不评价真实交易盈利能力。

### 1.3 要回答的三个问题

1. Optiver 工程特征相比原始字段，能否稳定降低样本外 MAE？
2. Alpha101-inspired 高频因子是否提供额外信息？筛选能否在降低成本的同时保留或改善预测能力？
3. 神经网络是否能提供树模型没有充分利用的信息，值得额外计算成本？

这些问题允许得到否定结论。不预设 Alpha101、筛选或 DL 必须有效。

## 2. 整体链路

```text
数据接入与字段审计
        ↓
冻结时间划分与最终留出集
        ↓
零预测 / 训练集标签中位数 / 原始字段 LightGBM 基线
        ↓
候选特征生成
  ├─ Optiver 微观结构特征
  ├─ 日内历史变化与滚动特征
  ├─ 同时刻横截面与收盘阶段特征
  └─ 少量 Alpha101-inspired 高频因子
        ↓
质量检查 + IC / 相关性诊断
        ↓
LightGBM 全量特征模型 ←→ 筛选特征模型
        ↓
多折时间验证 + 分组消融 + 成本比较
        ↓
误差分析与保留/删除决策
        ├─ 形成稳定主链路 → 定型 → 最终留出评估
        └─ 有明确增强假设 → 小型 DL → 融合实验 → 重新验证
        ↓
历史逐批回放 + 离线/在线特征一致性检查
        ↓

```

时间验证约束贯穿整条链路。逐批回放从最小基线阶段就开始搭建，不等模型定型后才检查。

## 3. 阶段一：数据接入与字段审计

### 要做什么

1. 从官方来源取得训练数据和示例推理文件，保留原始数据副本，记录来源和版本。
2. 核对字段类型、数据规模、股票数量、日期范围、采样时间和缺失情况。
3. 检查 `(stock_id, date_id, seconds_in_bucket)` 是否唯一；重复键要先查原因，不能直接静默删除。
4. 时间序列运算按股票、日期、日内时间排序；同时检查是否缺失时间点。
5. 核对价格的归一化方式、size 字段单位和竞价字段含义，形成数据字典。

### 清洗规则

- `target` 缺失的行不参与监督训练，不能将其标签填为 0；其可用输入可保留为后续时点的历史上下文。
- 特征中的 Inf 转为缺失值，追踪其来源，例如除零或极小分母。
- 特征缺失先区分数据问题、历史窗口不足、竞价阶段性缺失，不一律填 0。
- LightGBM 数值特征可先保留 NaN；DL 的填充与标准化另行定义，参数仅在训练部分拟合。
- 裁剪阈值、填充值、股票历史统计量只能从训练历史拟合，不从全量数据计算。
- `row_id` 等标识字段保留用于结果对齐，不直接作为模型特征。

### 阶段产出

数据概况报告、字段字典、缺失与重复键报告、时间完整性检查结果，以及可重复读取的数据入口。

## 4. 阶段二：冻结时间验证协议

### 4.1 开发集与最终留出集

以下是日期范围为 0～480 时的示例，实际边界在数据审计后一次性确定：

| 用途 | 训练日期 | 评估日期 |
|---|---|---|
| 开发折 1 | 0～239 | 240～289 |
| 开发折 2 | 0～289 | 290～339 |
| 开发折 3 | 0～339 | 340～399 |
| 最终留出评估 | 定型后用 0～399 重训 | 400～480 |

开发折用于比较特征、参数、筛选和模型方案；最终留出集不参与这些选择。若最终留出结果被用于修改方案，就应如实说明它已被用于开发，不能继续称其为独立测试。

### 4.2 每一折内部的流程

```text
该折训练部分
  → 拟合预处理参数、计算因子诊断与筛选依据
  → 必要时在训练部分内部划出末段，用于早停或筛选
  → 确定特征集合与训练轮数
  → 在该折训练部分重新拟合
  → 对该折后续日期预测并记录 MAE
```

- 不使用该折评估标签计算 IC 排名、决定缺失阈值或拟合编码器。
- 开发折评估结果可以用于方案选择，但选择后的开发成绩不是独立最终成绩。
- 决定 Top-N 的排序在每折训练部分重新生成，不提前用全部数据生成一张固定排名。
- 最终训练轮数由开发实验或训练集内部早停确定，不使用最终留出集早停。
- 同一时间截面的股票不能随机分散到训练和验证中。
- 若切分点落在日内，剔除标签未来 60 秒覆盖区间跨界的训练样本。
- 按完整交易日划分时仍核查标签区间和可用时间，不机械添加固定行数的 gap。

### 阶段产出

固定的日期划分配置、每折训练/评估索引，以及标签时间边界与数据泄漏检查。

## 5. 阶段三：建立最小预测闭环

先不加入 Alpha101 和 DL，建立三个参考模型：

| 基线 | 做法 | 作用 |
|---|---|---|
| Zero | 所有预测为 0 | 基本参考线 |
| Median | 预测该折训练标签中位数 | 检查 L1 损失下的常数基线 |
| Raw LightGBM | 原始可用字段 + 时间/股票标识的合理处理 | 测量原始信息的预测能力 |

LightGBM 初始采用 `objective=regression_l1`、`metric=mae`。`stock_id` 按类别身份处理并固定编码规则；`date_id` 首先用于切分和追踪，不默认当作数值信号输入。冻结一套简单参数，先验证流程，不进行大规模调参。

预测必须能够与原始行一一对应。记录每个基线的逐折和逐日 MAE，作为后续所有增益的比较对象。

### 阶段产出

可重复的训练/预测入口、基线结果表、带日期和股票键的样本外预测，以及最小逐批回放入口。

## 6. 阶段四：候选因子生成

### 6.1 A 分支：Optiver 微观结构特征

| 特征组 | 例子 | 想表达的信息 |
|---|---|---|
| 价格关系 | spread、mid price、WAP 与 mid/reference 的差 | 价差与价格偏离 |
| 盘口失衡 | `(bid_size-ask_size)/(bid_size+ask_size)` | 买卖盘相对强弱 |
| 竞价失衡 | signed imbalance、未匹配比例 | 集合竞价压力与方向 |
| 复合特征 | spread × liquidity imbalance | 价差与买卖压力的交互 |
| 有限组合 | 同类价格/size 的 doublet、triplet 比率 | 多变量相对关系 |

先实现少量有明确含义的特征，再逐组增加组合。分母接近零时使用明确的缺失或稳定化规则，不用一个通用 epsilon 掩盖单位差异。

### 6.2 B 分支：日内历史变化

围绕 WAP、spread、盘口/竞价失衡构造 lag、diff、收益变化、滚动均值和波动。

- 初始候选时间窗口可用 10、30、60、120 秒，具体数量通过开发实验控制。
- 默认在 `(stock_id, date_id)` 内计算日内历史，日切时重置日内状态。
- 区分“过去 6 条记录”和“过去 60 秒”；存在时间缺口时不能直接等同。
- 窗口只使用当前与过去记录，不使用中心窗口或向未来回填。
- 明确 `min_periods`、标准差自由度、首条记录和窗口不足时的返回规则。

跨日历史特征如需加入，单独定义，不与日内 lag 混用。

### 6.3 C 分支：横截面与收盘阶段

在已经收到的同一 `(date_id, seconds_in_bucket)` 数据内，计算短期动量、spread、失衡的排名、均值和相对偏离。

同时保留 `seconds_in_bucket`，研究信号在不同收盘阶段的差异。阶段边界应事先指定或在训练内部研究，不能按最终测试表现选择。

横截面排名不能使用整天的未来记录；股票统计量不能从包含评估日期的全量数据拟合。归一化价格的均值不直接称为真实市场指数。

### 6.4 D 分支：Alpha101-inspired 高频因子

复用 `rank`、`delay`、`delta`、`ts_rank`、滚动相关性、滚动标准差、线性衰减等算子和公式结构，先构造约 10～20 个候选。

可优先研究：

- 短期 WAP 变化的横截面排名。
- 盘口失衡的滚动均值、变化和线性衰减。
- spread 与失衡的历史滚动相关性。
- 当前动量在自身最近一段历史中的时间序列排名。

这些是待检验的新候选，不声称等同于原版 Alpha101，也不预设有效。

适配约束：

- `rank` 明确表示同一时刻跨股票排名；`ts_rank` 表示同一股票历史窗口内排名。
- WAP 不直接等同于原公式中的成交 VWAP；盘口 size 不直接等同于成交量。
- 将日频窗口替换为秒级窗口是新假设，需要记录和验证。
- 依赖缺失 OHLC、行业或其他字段的公式先跳过，不强行补出输入。
- 不为了凑足 101 个而增加不可解释的替换。

### 6.5 因子登记表

每个因子记录：名称、所属组、公式、输入字段与单位、窗口、分组键、最大历史需求、缺失处理、来源/改编说明、代码版本。

### 阶段产出

可追溯的候选特征矩阵、因子登记表，以及可供离线和逐批推理复用的特征实现。

## 7. 阶段五：质量检查与因子诊断

### 7.1 基础质量检查

检查缺失率、Inf 比例、唯一值数、近常数列、异常分布和重复列。阈值由训练部分决定，阶段性缺失特征需按日内阶段检查，不按整体缺失比例直接删除。

优先删除错误实现、无有效观测和明确重复的列。对是否有预测价值的判断留给后续实验。

### 7.2 IC / RankIC

```text
每个同一时刻的股票横截面
  → corr(factor, target) 得到 IC
  → corr(rank(factor), rank(target)) 得到 RankIC
  → 按天汇总
  → 比较均值、方向和跨天稳定性
```

常数截面、样本不足或缺失配对不足时记为不可计算，不能默认为 0。明确截面到日、日到总体的权重规则，并保留有效样本数。

低 IC 不直接淘汰：非线性关系、条件性信号和状态特征可能需要组合后才有效。ICIR 可作为描述统计，不把相邻时间点视为独立样本推导显著性。

### 7.3 相关性与冗余

观察绝对相关系数，包括接近 −1 的反向冗余。可把 `|corr| > 0.9` 当作候选分组提示，但不是强制删除规则。

对同一组中的特征，结合含义、计算成本、缺失情况和后续消融决定保留项。始终保留全量有效特征模型作为对照。

### 阶段产出

质量报告、训练内部 IC / RankIC 报告、相关性分组，以及需要进一步检验的候选删减方案。

## 8. 阶段六：LightGBM 与增量价值实验

### 8.1 实验矩阵

| 编号 | 输入/方法 | 主要问题 |
|---|---|---|
| E0 | Zero / Median | 常数基线表现如何？ |
| E1 | 原始字段 + LightGBM | 原始数据提供多少信息？ |
| E2 | E1 + Optiver 特征，包括时序/横截面/阶段特征 | 工程特征是否有效？ |
| E3 | E2 + Alpha101-inspired 因子 | 公式适配是否有增量？ |
| E4 | E3 经筛选后重训 | 筛选是否改善精度或成本？ |
| E5 | 最佳树模型 + DL | DL 是否提供互补信息？ |

E2 内部再逐组增加或删除微观结构、时序、横截面等模块，避免一次增加全部后无法归因。

### 8.2 特征筛选与消融

1. 先训练全量有效特征模型。
2. 使用训练内部的 LightGBM importance，以及必要的 SHAP/内部样本外分析，提出删减假设。
3. 按特征组消融，再做少量 Top-N 实验，例如 Top-20、Top-40 与 All；数量依实际特征规模调整。
4. 每种候选集合重新训练，在相同开发折上比较。
5. 若筛选模型不改善 MAE，但明显减少推理成本，可作为单独的成本优化结论。

Importance / SHAP 是解释和提出假设的工具，不等于因果作用，也不单独证明样本外增益。相关特征可能分摊重要性，单列排名需要结合分组分析。

### 8.3 结果记录与保留标准

统一记录实验编号、代码版本、数据版本、日期划分、特征配置、参数、随机种子、各折 MAE、逐日 MAE、耗时和内存。

- 总体 MAE 按全部评估样本计算；另列各折/逐日结果，避免混淆加权与等权均值。
- 新方案必须与相同评估行上的基线比较，不能通过删掉难预测样本获得更低误差。
- 初期保持模型参数固定以比较特征；后期给主要候选可比的调参预算。
- 优先保留跨多个日期段有效、可解释且计算成本合理的变化，不以单折最低值定胜负。
- 若差异很小，检查不同种子和按天/连续天块重采样的不确定性，不按独立行重采样。
- 不预设必须达到某个虚构 MAE；所有结果表填写实际实验值。

### 阶段产出

可复现的对照实验表、最终候选因子集合、模型产物，以及每个特征组保留或删除的证据。

## 9. 阶段七：误差分析与是否启动 DL

在继续增加复杂度前，检查误差是否集中在特定日期、股票、流动性水平或收盘阶段；核对训练/评估差距、特征分布变化、缺失处理和推理一致性。

根据诊断提出下一步假设，例如：短期历史顺序可能未被滚动统计充分表达，或同一时刻股票关系仍有利用空间。

MAE 停止下降不代表显式因子已达到理论上限。DL 作为增强实验，只有在基础流程可靠、实验资源允许且问题明确后启动。

### 建议顺序

1. 小型 MLP：检验已有表格特征上的神经网络基线。
2. GRU：输入同一股票截至当前时刻的历史序列，检验顺序信息的增益。
3. Transformer：只有在已有实验支持进一步研究时，选择时间注意力或横截面注意力中的一种假设。
4. 比较 DL 独立预测与 LightGBM 的误差互补性。
5. 在开发集选择简单预测融合权重，再评价未参与选择的数据。

时间模型只允许观察当前及过去；输入整段序列时需要因果掩码或等效约束。横截面模型只能使用当时已收到的股票信息。填充、标准化和早停同样遵循时间验证协议。

### 隐藏表示接入 LightGBM：后续可选研究

不将“64 维 embedding → LightGBM”设为默认路线：

- 使用同一批标签训练编码器，再提取训练内表示供下游学习，存在过拟合与分布差异风险。
- 不同折编码器的隐藏维度通常没有自动对齐，不能简单拼接成统一的 h1～h64。
- 简单的无泄漏原型可使用早期时段训练并冻结编码器、后续时段训练下游模型、再后续时段评估，但会减少可用训练数据。
- 预测级 stacking 使用按时间生成的样本外预测，不直接套默认随机交叉验证。

这一分支的成功标准是可信的样本外增益与可接受的额外成本，不是神经网络规模。

## 10. 阶段八：逐批推理、最终评估与交付

### 10.1 从 V1 开始的历史回放

```text
历史数据按时间送入
  → 更新当前已知状态与历史缓存
  → 生成该批可用特征
  → 按固定列名/顺序输入模型
  → 输出对应行预测
  → 与离线计算结果核对
```

至少覆盖首批数据、日切、缺失股票、缺失时间点、窗口不足、极小分母和缺失竞价字段。

- 对特征和预测设定明确的数值误差容忍度，报告不一致的键和列。
- 检查截断未来数据后，过去时刻特征是否不变，以检测未来信息依赖。
- 推理历史缓存必须满足特征声明的历史需求，并明确定义初始状态。
- 时间批次中尚未到达的数据不能参与横截面运算。
- 第一阶段不使用未来 revealed targets 或在线更新模型；如后续加入，单独审计标签实际可用时间。

### 10.2 最终留出评估

在开发完成后冻结特征定义、筛选方法、参数、训练轮数及融合规则，用开发历史重训，再评估最终留出集。同步记录精度、成本和逐批回放检查结果。

若最终评估后用所有允许的已标注历史重新训练交付模型，区分“用于独立评估的模型”与“最终重训模型”，不把后者声称为已在原留出集上独立测试。

Kaggle 推理接口以实际可访问的官方示例为准；即使无法进行在线提交，本地时间回放和冻结留出评估仍作为项目验收依据。

### 阶段产出

模型文件、特征列表、预处理参数、配置快照、实验记录、样本外预测、最终评估报告及推理入口。

## 12. 开发里程碑与完成标准

| 阶段 | 范围 | 完成标准 |
|---|---|---|
| M0 | 数据审计与验证协议 | 字段、日期、标签边界和留出集已确定 |
| M1 | 最小闭环 | 三类基线能训练、评估、对齐预测，初步回放可运行 |
| M2 | Optiver 特征 | 特征组逐步消融，有时间样本外对照 |
| M3 | Alpha101-inspired 与筛选 | 能回答新增公式和筛选是否有增量价值 |
| M4 | 主链路定型 | 多折结果、成本、逐批一致性与独立留出评估完整 |
| M5（可选） | DL 增强 | 有独立预测/融合对照，说明增益或失败原因 |

V1 的完成边界是 M0～M4，不依赖 DL 成功。最终报告应清楚区分借鉴的特征、自己适配的候选、无效实验和经过验证的改进。
